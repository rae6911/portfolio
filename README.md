# Joshua Berdin – Portfolio

React + Vite + Tailwind CSS v4.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

- Edit your content in `src/data.js`.
- Palette lives in `src/index.css` under `@theme` (night, surface, lime, snow, mute); lime is sampled from the rae logo.
- Replace `public/berdin-cv.pdf` to update the CV download.
- Logo files live in `public/` (`rae-logo.png`, `rae-mark.png`, `favicon.png`).

- Motion: scroll reveals live in `Reveal.jsx`, parallax in `Parallax.jsx` (speed prop), and everything respects reduced-motion settings.
